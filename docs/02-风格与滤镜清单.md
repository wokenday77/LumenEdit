## 1. 统一数据模型：一份数据，四处复用

这是回答你「滤镜要和风格共用同一套数据来源，不要另起炉灶」的核心设计。

<此处见对话中的架构图>

```
FilterDefinition（滤镜 = 最小渲染单元，14 款）
├─ id / name / category / reference / description
├─ lut: LUTSpec?                 ← 烘焙 3D LUT 的参数（不是读 PNG，是代码算出来的）
├─ nativeSteps: [NativeOp]       ← 原生 CIFilter 步骤（模糊/颗粒/暗角/锐化等 LUT 做不了的）
└─ defaultIntensity / intensityRange

StylePreset（风格 = 滤镜 + 强度 + 全套调整 + 相机侧建议，10 款）
├─ id / name / category / reference / description / suitableScenes
├─ filterID + filterIntensity
├─ adjustments: EditRecipe        ← 亮度/对比/饱和/色温/色调/高光/阴影/锐化/降噪/暗角/颗粒/褪色
├─ captureHint: CapturePreset     ← EV、白平衡色温建议
└─ previewCSS                     ← 缩略图近似（网页原型与 App 内滤镜条共用）

ScenePreset（场景 = 拍摄侧 + 修图侧的建议组合，5 个）
└─ id / name / defaultStyleID / defaultFilterID / adjustments / captureHint
```

**四处复用同一份数据：**

1. `FilterCatalog.swift` —— iOS 侧渲染（P4 落地）
2. 网页原型里的一个 JS 对象 —— **同一份字段，手工保持同步**（后续可用脚本从一处生成另一处）
3. App 内滤镜条缩略图 —— 用 `previewCSS` 对应的近似参数渲染，不必跑完整 LUT
4. 将来的预设分享文件（JSON 导出/导入）

**强度（intensity）怎么实现，这点很关键：**

- **纯 LUT 类滤镜**（大多数）：在**生成 LUT 时**按 `intensity` 在「输入色 ↔ 风格色」之间线性插值。
  好处：强度 0 时严格等于原图（不会有 1/255 的偏差堆积），且零额外渲染开销。
- **含原生步骤的滤镜**：用 `CIColorMatrix` 把处理结果的 alpha 缩放到 `intensity`，再 `composited(over: 原图)` 混合。
  这是不写自定义 kernel 时最可靠的混合方式。

**LUT 生成的三条纪律：**

1. 用 `CIColorCubeWithColorSpace`，色彩空间**固定 sRGB**（不加色彩空间参数会导致色偏）
2. 尺寸 32³（32768 个采样点）—— 精度足够，生成耗时在毫秒级，不要用 64³（内存与耗时翻 8 倍，肉眼无差别）
3. 采样点在**线性空间**里等距分布（这决定了肤色过渡是否平滑，是 LUT 质量的分水岭）

## 3. 滤镜库清单（14 款）

### 通用实现约定（先讲清楚，后面不再重复）

| 环节 | 做法 | 为什么 |
|---|---|---|
| 色彩调性主体 | `CIColorCubeWithColorSpace`（32³，sRGB） | 一次采样完成所有通道变换，GPU 友好 |
| 曲线 | `CIToneCurve`（5 控制点） | S 曲线、高光 rolloff、抬黑位用它最直接 |
| 饱和 | `CIVibrance`（自然饱和）优先，需要硬提才用 `CIColorControls.saturation` | Vibrance 会保护肤色不过饱和 |
| 局部对比（结构） | `CIUnsharpMask` 大半径小强度（radius 8–12 / intensity 0.2–0.4） | 这才是"结构/clarity"的等效做法，不是锐化 |
| 细节锐化 | `CISharpenLuminance`（小半径） | 与大半径的 clarity 分工不同，不要混用同一个参数 |
| 柔光/发光 | `CIBloom`（radius + intensity） | 人像柔光的标准做法 |
| 高光/阴影 | `CIHighlightShadowAdjust` | 一次调用同时压高光提阴影 |
| 降噪 | `CINoiseReduction`（noiseLevel / sharpness） | 与锐化互相打架，顺序上降噪在前 |
| 暗角 | `CIVignetteEffect`（center / radius / intensity） | 需要椭圆范围，比 `CIVignette` 可控 |
| 颗粒 | `CIRandomGenerator` → `CIColorMatrix` 去色 → `CIOverlayBlendMode` 叠加 | 唯一可靠的无第三方颗粒方案 |
| 渲染顺序 | 线性化 → **LUT** → 高光阴影 → 柔光 → 降噪 → 锐化/结构 → 颗粒 → 暗角 → 输出 | 局部效果必须在色彩变换之后，否则会被后续变换放大失真 |

## 6. 待你确认的三件事

1. **清单够不够**：10 款风格 + 14 款滤镜（+3 款组合滤镜）。备选里的 VSCO C1、富士 Eterna、VSCO M5、HB1、Lightroom Warm Gold / Deep Blue 要不要现在加进来？
2. **风格条要不要拆成两条**：你要求「风格选择条」和「滤镜选择条」分开。现在清单里风格本身就是"滤镜 + 参数"的组合，如果两条都放全部 10+14 项，用户在真机小屏上会分不清区别。我的建议是：
   - **风格条**放 10 款风格（一键成片，含参数）
   - **滤镜条**放 14 款滤镜原味（只调色，不含参数）
   - 两者视觉上必须能看出差异（风格卡带参数徽标，滤镜卡纯色块）
3. **命名**：现行名称直接用「柯达 Portra 160」「醒图马卡龙」这类品牌名，**自用没问题**。如果你打算以后分发给朋友或上架，我建议现在就换成备选名（每款我都给了）。要换的话我一起改。
