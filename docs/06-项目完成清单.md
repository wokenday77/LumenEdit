**在 Mac 上从零跑起来**

```bash

git clone <仓库地址> LumenEdit && cd LumenEdit
xcodegen generate          # .xcodeproj 不入库，每次拉完/增删文件后都要重跑
open LumenEdit.xcodeproj   # 改 Bundle ID → 选 Apple ID 团队 → ⌘R（必须真机）
```

```bash

  -destination 'generic/platform=iOS' -sdk iphoneos CODE_SIGNING_ALLOWED=NO build
```
